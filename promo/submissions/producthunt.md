# Product Name:
WalletLens

# Tagline:
The free, private, open-source portfolio tracker with AI analysis

# Description:
WalletLens is a privacy-first, open-source portfolio tracker that supports crypto, stocks, gold, silver, real estate, and cash — all in one dashboard.

**Why it's different:**
- Zero accounts — no sign-up required
- Zero tracking — no analytics, no data collection
- Zero cloud — all data stays on your device
- Open source — every line of code is public on GitHub

**Key Features:**
- 🎙️ AI Voice Import — say your holdings, AI parses them
- 📸 Screenshot Import — screenshot any exchange app, AI reads it
- 📄 Excel/CSV Import + Export
- 🤖 AI Magic Indicator — 5-signal composite direction per holding
- 🛡️ Portfolio Guardian — anomaly and risk detection
- 💰 Zakat Calculator — auto-calculate 2.5% Nisab
- 📱 PWA + Android app — works offline

**Built with:**
React, Vite, Cloudflare Pages, Claude AI, Deno Deploy
