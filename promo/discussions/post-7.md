## Overview

WalletLens is a full-stack portfolio tracker built with modern web technologies and packaged as a native Android app.

---

## Frontend

- **React + TypeScript** — Component-based UI
- **Capacitor** — Bridges web app to native Android
- **Vite** — Lightning-fast builds
- **PWA** — Installable on any device, works offline

## Backend (Edge)

- **Cloudflare Workers** — Serverless edge functions
- **Cloudflare Pages** — Static hosting with global CDN
- **Deno** — Runtime for background jobs

## Data

- **CoinGecko API** — Real-time crypto prices
- **Yahoo Finance** — Stock and commodity prices
- **Local Storage** — All user data on device
- **IndexedDB** — Offline data persistence

## AI & Analysis

- **Magic Indicator** — Custom algorithm fusing 5 signals
- **Portfolio Guardian** — Anomaly detection engine
- **AI Coach** — Context-aware portfolio assistant
- **Technical Analysis** — RSI, MACD, Bollinger, On-chain

## Mobile

- **Capacitor Native Shell** — Android app wrapper
- **Bottom Navigation** — Dashboard, Watchlist, Analysis, Alerts, Backup
- **Biometric Auth** — Fingerprint unlock
- **Push Notifications** — FCM HIGH priority, no Firebase tracking

## Privacy Architecture

- Zero accounts — No signup or login
- Local-first — All data on device
- No analytics — No tracking whatsoever
- Open source — Every line of code is public
