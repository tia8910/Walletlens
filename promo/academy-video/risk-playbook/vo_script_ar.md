# Egyptian Arabic voice-over: recording script

There are 13 lines. Record each one as its own WAV file (`01.wav` … `13.wav`, mono or stereo, any sample rate) in one folder. Then run:

```bash
./make.sh ar path/to/that/folder
```

The tone is a funny Egyptian storyteller, like a friend telling a story from school with comic timing. Keep each line inside its time slot. If a line runs long, say it a little faster rather than cutting words. The politics stays generic: say "رئيس دولة" (a world leader), never a real name.
