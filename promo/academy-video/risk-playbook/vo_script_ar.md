# Egyptian Arabic voice-over: recording script

There are 11 lines. Record each one as its own WAV file (`01.wav` … `11.wav`, mono or stereo, any sample rate) in one folder. Then run:

```bash
./make.sh ar path/to/that/folder
```

The tone is a friendly Egyptian storyteller, like a friend telling you something that happened at school. Keep each line inside its time slot. If a line runs long, say it a little faster rather than cutting words.
